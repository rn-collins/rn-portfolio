# RN 100 Builds — carousel production blueprints

This directory is the production handoff for the 100 build-specific, seven-slide carousels. It is an editorial specification, not evidence that a Canva design, export, publication, or approval exists.

## Required slide order

1. Hook — use the exact mapped live cover. Do not replace, crop, or detach an official source-context cover from its credit and limitation.
2. Problem — state the build-specific tension without inventing a user, result, or failure.
3. System — show inputs, transformation or decision, human authority, and output with RN-owned diagrams or verified prototype views.
4. Evidence — distinguish primary-source context from evidence of prototype performance.
5. Demo — show one authentic bounded prototype state or a clearly labeled faithful diagram.
6. Implications — separate what the build makes possible from what it does not establish.
7. CTA + sources — identify the build, link the canonical dossier, and preserve credits, rights, and no-endorsement language.

## Production rules

- Canvas: 1200×1500, 4:5 portrait; keep text within a 96 px safe inset.
- Type: minimum 48 px body type at master size; verify at a 360 px-wide mobile viewport.
- Accessibility: WCAG AA contrast; never use color alone; sequential reading order; meaningful alt text; captions/transcripts for motion.
- Rights: use only RN-owned design/prototype material or the exact official source treatment already mapped in the record. Logos, seals, portraits, trade dress, and unspecified third-party material remain excluded.
- Claims: never imply endorsement, deployment, testimonial evidence, causation, safety, compliance, performance, effectiveness, or outcomes absent direct evidence.
- Records: keep source, credit, rights line, claim boundary, rollback URL, final checks, and export checksums outside Canva as the canonical record.

## Repurposing

- Instagram: seven 4:5 slides; add the supplied alt text manually.
- LinkedIn: accessible seven-page PDF plus canonical dossier link.
- Reels/TikTok: animate the sequence silent-first; preserve captions, credits, boundaries, and the CTA.
- Web/newsletter: use the mapped cover as preview and link/embed the dossier. Never detach a source-context image from its caption and credit.

## Release gate

A carousel remains unproduced until an actual design/export record exists. Before publication record editorial, visual, accessibility, rights, claim-scope, mobile, link, and checksum review. Canva generation is not authorized merely by this blueprint.
