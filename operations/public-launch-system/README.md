# RN Builds distribution system

This folder contains a complete editorial operating system for distributing the 100 builds. Nothing in it schedules or publishes a post.

- `professional-framing.md`: site-ready positioning, methodology, role language, prototype boundary and work-with-RN pathway.
- `linkedin-copy-and-order.csv`: 100 individualized LinkedIn drafts, hooks, propositions, strategic release order, URLs, hashtags and X/Instagram variants.
- `release-calendar.md`: 34-week, three-post-per-week calendar with deliberate review points.
- `publishing-tracker.csv`: operational register; every post begins as “not scheduled.”
- `publishing-checklist.md`: human approval, accessibility, evidence, link and measurement gates.

The first 12 posts intentionally cross fields and lead with the capstone plus strong explanatory builds. The remaining sequence interleaves fields to prevent the feed from feeling like a chronological dump. The copy is grounded in the final on-site transcripts; it still requires RN's voice-level sign-off before posting. This operating system is retained with the authoritative website source, but it does not schedule or publish anything.
