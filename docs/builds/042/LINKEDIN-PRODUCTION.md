## Storyboard and on-screen transcript

The film is silent-first. All meaning is present as on-screen text; these six scenes run for three seconds each.

1. **A PROMPT IS NOT A JOB DESCRIPTION.** An agent can produce fluent work while its purpose, authority, tools, accountable owner, prohibited actions, and required review remain undefined.
2. **PURPOSE · INPUT · OUTPUT · OWNER.** Use a synthetic role to name the bounded task, accepted inputs, expected artifact, responsible human, affected people, success criteria, and consequence.
3. **ALLOW · DENY · REQUIRE APPROVAL.** Assign only necessary tools and data. Separate read, draft, recommend, communicate, transact, and delete permissions; attach evidence and expiry.
4. **PERMISSION · RISK · EVALUATION.** When work moves in or out, recompute required access, consequence, evaluation coverage, human review, inherited ownership, and the safe fallback.
5. **REVIEW · ESCALATE · ABSTAIN · STOP.** Require review before consequential action. Preserve uncertainty, failed tools, boundary violations, escalation routes, termination rules, and exact state-only replay.
6. **GIVE THE AGENT A REAL JOB.** An AI agent has a real job only when its role, tools, boundaries, review points, and stop conditions are explicit.
