# Recognizable entity and visual-source package schema

Each Build 035–067 record uses the shared 068–100 field contract: build ID/title; recognizable entity and relevance; entity-led hook; current cover/opening-frame asset; issuer/creator; rights and permission status; credit; alt text; orientation/dimensions; crop guidance; claim-to-visual scope; official/primary candidate-search log; generated-fallback reason; Canva template/slide types; platform adaptations; CTA; and production status.

## Selection standard

Recognizable does not mean merely famous. An entity must help the intended visitor understand the build’s domain, authority, constraint, or source context. Fame, a logo, a portrait, or an institutional seal is not a substitute for relevance and never supplies reuse permission.

## Release gate

An external visual fails closed unless the package records an exact source page, exact asset URL, issuer/creator, rights statement, permission decision, credit, alt text, dimensions, crop direction, and limited claim-to-visual explanation. Public visibility never substitutes for authorization. Creator-owned typography is labeled as a generated fallback, not documentary evidence. Canva generation is outside this audit.

`visualCandidateSearch.searched` preserves rejected candidates. A null asset URL is an explicit rejection signal, not an omission: the official context page was reviewed but no exact asset was selected or cleared.
