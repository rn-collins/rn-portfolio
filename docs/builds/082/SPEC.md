# Build 082 — Audience Intelligence Knowledge Graph

## Canonical contract

Build 082 uses Builds 002, 011, 028, 062, and 081 and creates `cap:082`. Its exact artifacts are `Audience Ontology` and `Trust & Influence Edges`.

082-A is **Audience Intelligence Knowledge Graph**: it connects audiences, needs, language, behaviors, trusted sources, misconceptions, channels, relationships, and conversion evidence. Registry title: **How Does This Audience Actually Think?** Job: **Map audience needs, language, trust, misconceptions, relationships and contexts beyond demographics.** 082-B is **An Audience Is Not a Demographic Box**: a persona card expands into a dynamic relationship graph. On the web, a persona card expands into a dynamic trust, need and language graph.

## Frozen synthetic fixture

The engine admits exactly five fictional audience-context graphs in fixed order: Cedar, Harbor, Lattice, Mesa, and Orbit. These are bounded decision contexts, not demographic or psychographic segments. Each graph contains exactly three invented source records, nine nodes, nine descriptive edges, and explicit unknowns. There are no real people, audiences, interviews, observations, actions, identities, demographics, locations, protected traits, or tracking events.

The nine-node ontology preserves `AUDIENCE-CONTEXT`, `NEED`, `LANGUAGE`, `BEHAVIOR`, `TRUSTED-SOURCE`, `MISCONCEPTION`, `CHANNEL`, `RELATIONSHIP`, and `CONVERSION-EVIDENCE`. Every node and edge retains source evidence and a caveat or descriptive status. “Trusted” means only named as trusted in one invented record. “Behavior” and “conversion evidence” are fixed fictional interface events, not stable traits, intent, demand, conversion, or predictions. “Influence” edges are descriptive fixture relationships, not causal, authoritative, or predictive claims.

Only the five byte-for-byte frozen presets are admitted. Additional, mutated, real, identity-bearing, hostile, or unrecognized input returns `INVALID`, no graph, and an empty ontology. There is no free text, network retrieval, real audience data, tracking, identity linkage, profile enrichment, demographic or protected-trait inference, psychographic inference, scoring, ranking, prediction, or fallback.

## UI and export contract

082-A uses native select label `AUDIENCE CONTEXT` and buttons `RESTORE CEDAR CONTEXT` and `EXPORT AUDIENCE GRAPH`. The exact export filename is `synthetic-audience-intelligence-graph.json`. The payload contains version `082.1.0`, exact lineage, exact artifacts, full admission block, input, result, and replay data.

082-B starts closed and uses `EXPAND PERSONA CARD`; its live status says `One persona became a bounded relationship graph`. The transformation must preserve all nine ontology types, evidence links, caveats, descriptive edge status, bounded context, and unknowns. It cannot present a targeting segment or behavioral prediction.

Both routes require semantic native controls, visible keyboard focus, live status, reduced-motion support, print support, and no horizontal document overflow at 320 CSS pixels. Color is never the only carrier of node type, evidence, caveat, or unknown.

## Privacy, audience, trust, and decision boundaries

Every source, person, audience context, need, phrase, behavior, source, misconception, channel, relationship, action, and date is fictional. Fixture evidence does not establish how any real person or group thinks, speaks, behaves, trusts, relates, decides, or converts.

The engine cannot determine identity, demographic attributes, protected traits, psychographics, personality, vulnerability, preference, sentiment, intent, trustworthiness, authority, influence, conversion probability, demand, need, eligibility, or outcome. It cannot support profiling, targeting, persuasion optimization, manipulation, personalization, advertising, moderation, hiring, education, insurance, credit, housing, clinical, legal, public-benefit, political, or resource-allocation decisions.
