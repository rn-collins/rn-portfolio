# Build 038 — Domain AI Evaluation Studio

Frozen canon: the evaluation is for one declared use case, task, consequence and population contract. Uses Builds 012, 020 and 032; creates cap:038.

Engine 038.2.0 requires unique metrics with direction, units, validity scope, frozen non-negative weights totaling 100, per-metric minimums evaluated against conservative 95% interval bounds, and common, rare and intersectional slices. Each slice pins model version, sample size, representativeness declaration, evidence method/date, dataset ID/version and leakage check. Missing values never become silent passing scores. Required-slice or evidence gaps block comparison; aggregate rank never overrides a metric gate. Worst-slice and model-ID tie-breaks are deterministic.

The fixture is synthetic and browser-local. Sample floors are control checks, not a power analysis; representativeness flags are declarations, not population proof. Results do not establish model quality, generalization, fairness, safety, certification or deployment authorization. Authenticated browser, physical-device/manual accessibility, hosted CI and independent domain review remain external gates.
