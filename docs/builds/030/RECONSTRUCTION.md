# Build 030 — complete reconstruction

Canonical public record: `/100-builds/030/reconstruction`.

## Release disposition

**REVISE, then publish as the second flagship.** The versioned deterministic engine, declared mappings, interaction warnings, evidence validation, privacy guard, and replayable export are real. “Simulator” is retired as the lead promise because no interface configuration can simulate a disabled person or lived experience.

## Technical contract

Seven transient interface conditions map to nine explicit repair controls. Two combined-condition interactions are registered. Evidence records fail closed when identity, HTTPS source, scope, uniqueness, date, or freshness is invalid. States are CONTROL BLOCKED, MAPPED GAPS, or MAPPED CONTROLS PRESENT. The last state never means repaired, accessible, usable, localized, conformant, or compliant.

Selections remain component-local and are exported only on request. The mapping table is an RN teaching scaffold, not a WCAG-prescribed model.

4. Constrained-network measurement.
5. Representative-language and cultural-context evaluation.
