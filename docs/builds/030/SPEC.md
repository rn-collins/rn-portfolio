# Build 030 — Inclusive Experience Simulator & Repair Lab

Canonical job: Experience and repair an interface under different access, device, bandwidth, motion, color, language and cognitive conditions.

Canonical B-Web: An interface transforms live under constraints, then the visitor repairs it.

Canonical lineage: uses 002, 023, 024, and 029; creates cap:030; consumed by 032, 045, 047, 048, 049, 050, 051, 053, 071, 073, 095, 099, and 100.

## Derived implementation

030-A tests interface conditions rather than pretending to simulate people. Visitor-selected transient conditions map to explicit repairs, consent/minimization controls, evidence references, and a Build-029 change trace. The profile is not persisted and the repair record exports locally.

030-B transforms a synthetic interface from default assumptions through visible constraints to repair.

The profiles, mappings, sample interface, language, repair rules, statuses, and explanatory copy are derived. The build does not reproduce disability, culture, cognition, language community, or lived experience and does not certify WCAG, legal, cultural, translation, usability, or device compliance.
