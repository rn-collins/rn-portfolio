# Build 030 — Inclusive Experience Simulator & Repair Lab

Canonical job: Experience and repair an interface under different access, device, bandwidth, motion, color, language and cognitive conditions.

Canonical B-Web: An interface transforms live under constraints, then the visitor repairs it.

Canonical lineage: uses 002, 023, 024, and 029; creates cap:030; consumed by 032, 045, 047, 048, 049, 050, 051, 053, 071, 073, 095, 099, and 100.

## Derived implementation — engine 030.2.0 / mapping 030-map-2

030-A applies deterministic, inspectable mappings to a synthetic interface fixture. Selections describe interface constraints, not people, diagnoses, identities, preferences, devices, networks, languages, cultures, cognition, or lived experience. The engine evaluates individual mappings plus declared combined-condition interactions; it does not infer unregistered interactions.

`MAPPED CONTROLS PRESENT` means only that every declared mapping is enabled. It does not claim repair efficacy, usability, accessibility, localization quality, WCAG conformance, or legal compliance. Evidence records include stable IDs, HTTPS sources, scope, review dates, uniqueness, a 366-day freshness bound, and no future dates. Evidence guides the fixture; it does not certify outcomes.

The profile is transient React component state: this feature does not persist or submit it. An explicit download contains the original ordered state, derived findings, engine and mapping versions, evidence metadata, privacy boundary, deterministic ordering, and exact replay input. Users must not enter personal health, disability, identity, or confidential information.

030-B exposes the same three-stage story with ordered native Previous/Next controls, visible and announced status, focusable repaired actions, responsive layout, and reduced-motion CSS. It carries the same non-claims as A.

Manual testing with disabled people, assistive technologies, physical target devices, representative languages, and constrained networks remains required. Authenticated live-browser, physical-device/manual accessibility, GitHub-hosted CI, and LinkedIn media certification are independent release gates.
