## On-screen transcript / storyboard

1. **More data is not more intelligence.** Every collected field creates exposure, retention work, access pathways, and eventual deletion duties.
2. **Start with purpose.** Name the decision each field supports. Permission does not make unnecessary collection necessary.
3. **Test every field.** Necessary, optional, sensitive, derived, or prohibited: keep the reason and evidence visible.
4. **Minimize before collection.** Remove prohibited fields, default optional fields off, and replace sensitive detail with the least revealing form.
5. **Design the exit.** Assign retention, deletion, redaction, and downstream handling before the data enters the workflow.
6. **The safest data has no breach path.** The best data risk is data never collected.
