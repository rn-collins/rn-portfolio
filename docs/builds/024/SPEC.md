# Build 024 specification

## Frozen canon

- Title: Privacy & Data Minimization Engine
- Job: Determines which data is necessary, optional, sensitive, derived, prohibited, retained, or deletable.
- B-Web: A bloated intake shrinks to its justified minimum.
- Uses: 023
- Creates: cap:024
- Later consumers: 030, 031, 036, 049, 067, 083, 091, 097 and 099

## Derived implementation

The question, thesis, fixture, thresholds, labels, and interface copy are derived implementation choices. The functional build applies deterministic necessity, permission, sensitivity, derivation, retention, deletion, and redaction rules to a synthetic intake inventory. Build 023 is concretely inherited through purpose-specific permission state. Permission is treated as one control, not proof that collection is necessary or lawful.

The tool is a product-control demonstration, not legal advice or a determination that a real organization complies with privacy law.
