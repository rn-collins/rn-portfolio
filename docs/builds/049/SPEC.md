# Build 049 — What Works for You?

## Canon

- Job: Build a private sensory and context profile from preferences, sensitivities, goals and past responses.
- B-Web: A personal context constellation reorganizes as setting, goals and responses change.
- Uses: 023, 024, 030, 036.
- Creates: `cap:049`.
- Direct consumers: 050, 052, 053, 054, 096, 097.

## Product

Version A is a private, synthetic context instrument. Version B is a three-scene context story. Both demonstrate that supports can change with setting and goal. Neither asks for or stores personal information.

## Contract

Engine `049.1.0` validates a single named synthetic fixture, closed enums, sensory levels 0–3, and at most eight case-insensitively unique cues. Invalid input fails closed. Export is an atomic, state-only snapshot with an exact replay instruction.

## Boundaries

This is not diagnosis, treatment, medical advice, a disability determination, an accommodation decision, a fitness judgment, a fixed identity, or a prediction. Real use requires lived-experience, disability-justice, clinical-safety, privacy, and accessibility review.
