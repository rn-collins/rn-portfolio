# Build 001 — Publishable Release Gate

Build 001 is the quality benchmark for the entire A/B series. It may not be treated as public-ready merely because it compiles or looks polished.

## 001-A — Human Review Design Framework

### Adoption
- A first-time visitor can state what the tool does and when to use it without prior AI-governance expertise.
- Quick Check requires no account and can produce useful value in roughly one minute once the user knows their workflow.
- The deeper mode is optional; users do not need to complete long free-text fields before receiving value.
- Example scenarios cover legal/professional work, people decisions, health-adjacent use and operations without implying universal legal applicability.

### Utility
- Output diagnoses separate dimensions rather than hiding weaknesses behind one score.
- High-consequence scenarios elevate timing, authority and evidence deficiencies.
- Results prioritize the first three fixes and produce a reusable protocol.
- User can copy the protocol.
- Limitations clearly distinguish architecture quality from legal compliance and real-world effectiveness.

### Accuracy / defensibility
- Dimensions and explanatory copy must remain traceable to the underlying human-oversight research basis maintained for the build.
- Product must not certify compliance, safety, effectiveness or legal sufficiency.
- Recommendations must make consequence, human authority, practical capacity and evidence visibility explicit.

### Privacy / accessibility / QA
- Prototype processes assessment locally unless this architecture intentionally changes later.
- Keyboard operation, labels, focus visibility, contrast and mobile layouts must pass QA.
- Empty/partial/strong scenarios must be tested.
- No result should imply that presence of a human alone constitutes meaningful review.

## 001-B — Human in the Loop

### Stop + comprehension
- First beat reads without sound and establishes the familiar phrase immediately.
- Motion itself carries the argument: human drift, late intervention and ignored override cannot be decorative-only effects.
- Each beat remains long enough for comprehension while the following event begins before dead air suggests completion.

### Saveability
- Final intellectual-souvenir frame must remain legible long enough to pause/screenshot/save.
- Save frame communicates a reusable architecture, not merely the title of 001-A.
- Required payload: TRIGGER → EVIDENCE → QUALIFIED REVIEW → DECISION, supported by competence, time, authority, evidence, override, escalation, record and test.

### LinkedIn translation
- Master artifact works as an autoplay browser experience.
- Native LinkedIn export is silent-first motion, not a click-through dependency.
- Feed export must preserve safe text margins and legibility on mobile.
- Final CTA points to 001-A without turning the piece into an advertisement.

## Pair integrity
001-B must make the problem visible; 001-A must solve enough of that problem to justify the click. B may not promise capabilities A does not contain. A should reuse visual vocabulary/data structures from the pair where useful, and both must feel like one intellectual object with two interfaces.

## Conversion test
A credible target visitor should be able to move through: stop → understand → save → click → diagnose → receive useful output → understand RN's approach → find a contextual route to work/contact.
