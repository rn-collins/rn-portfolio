- B-Web: Feedback travels through triage, evidence, decision, change and measured outcome.
- Uses: 007, 019, 020, 029. Creates: cap:037.

CLOSED LOOP does not prove the report true, the change effective, harm remedied, duties satisfied, or a real person notified. No real report or personal data is processed.
