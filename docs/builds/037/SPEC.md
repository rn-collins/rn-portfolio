# Build 037 — Feedback → Change Governance Lab

## Frozen canon
- Job: Show what happens after someone reports that a system is wrong or harmful.
- B-Web: Feedback travels through triage, evidence, decision, change and measured outcome.
- Uses: 007, 019, 020, 029. Creates: cap:037.

## Integrity model — engine 037.2.0

The synthetic report carries distinct consent, safety/anti-retaliation, anonymity, contact permission, escalation, appeal/reopen, duplicate/related-report, and affected-person communication records. An anonymity request blocks stored identity. Related reports remain linked rather than silently merged.

Severity is a triage assertion with rationale, not verified harm. A response target is not an SLA guarantee. Every ordered stage has one owner, bounded authority scope, rationale, timezone timestamp, and scoped/redacted evidence with unique identity, source, freshness/expiry, and conflict handling. Stages cannot be skipped.

The decision record does not establish truth or fairness. The change must link to the originating feedback and include regression and rollback records. Implementation verification is distinct from outcome: the outcome stage requires a declared measured metric and, where contact is permitted, an affected-person communication record.

`GOVERNANCE RECORD COMPLETE` means structural records are present. It does not prove report truth, triage correctness, timeliness, valid consent, anonymity/retaliation safety, decision fairness, change efficacy, harm remedy, measured affected-person benefit, or compliance.

Lineage covers Build 007 learning architecture, Build 019 escalation, Build 020 decision evidence, and Build 029 change trace. Export preserves exact original/derived state, stage order, evidence, authority, safety/appeal/linkage records, engine version, replay input, privacy/redaction, and limitations. Do not enter real harm reports or personal, confidential, privileged, or security-sensitive material.

A/B provide native reversible keyboard controls, live status, described journey, focus visibility, 320px layout, and reduced-motion handling. Real reporter consent/safety and anti-retaliation review, triage/SLA operations, evidence conflict resolution, authorized decisions, regression/rollback, measured outcomes, affected-person communication, appeal/reopen practice, authenticated browser, physical-device/manual accessibility, hosted CI, and LinkedIn verification remain external gates.
