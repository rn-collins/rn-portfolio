## Storyboard and on-screen transcript

The film is silent-first. All meaning is present as on-screen text; these six scenes run for three seconds each.

1. **MORE AGENTS CREATE MORE HANDOFFS.** Splitting complex work can add specialization while multiplying lost context, duplicated effort, hidden permissions, coordination cost, and unowned failure.
2. **ROLE · OWNER · INPUT · OUTPUT.** Use a synthetic topology to bind each agent and person to a bounded job, accountable owner, permitted tools, evidence contract, review point, and stop rule.
3. **SOURCE · TRANSFORM · RECEIVER · ACCEPTANCE.** Pass the smallest necessary state. Preserve provenance, uncertainty, constraints, rejected work, authority, expected response, and proof that the receiver accepted it.
4. **BOTTLENECK · SUPERVISION · COST · FAILURE.** When a role or connection changes, recalculate queue pressure, human review, access, latency, spend, evaluation coverage, and every reachable failure path.
5. **CONTAIN · FALL BACK · ESCALATE · STOP.** Block loops, stale or conflicting state, unauthorized tools, missing owners, and failed required checks; preserve exact trace and accountable human intervention.
6. **CONTROL LIVES BETWEEN THE NODES.** An AI team is governed only when every handoff preserves purpose, authority, evidence, supervision, and a safe failure path.
