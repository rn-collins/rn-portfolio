## Launch post
Power is often described as if it were invisible. Usually, the harder problem is that the records sit in different systems.

Build 085 places source-linked ownership, funding, lobbying, advisory, procurement, standards and messaging relationships in one inspectable map. Then it lets the evidence threshold change—reported, declared, documented—without letting the conclusion outrun the record.

A connection is not misconduct. Funding is not quid pro quo. Access is not control. Sequence is not causation. Missing evidence stays unknown.
