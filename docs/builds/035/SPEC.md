# Build 035 — Data Exit & Portability Test

## Frozen canon
- Job: Test whether exported data is complete, readable, reusable and actually movable elsewhere.
- B-Web: Data attempts to leave one system and survive another.
- Uses: 010, 026, 029. Creates: cap:035.

035-A tests a synthetic source schema through inclusion, machine readability, provenance, and target mapping, then exports an exact local test record. 035-B makes a record attempt to cross between systems. Native controls, live status, visible focus, 44px actions, 320px layout, and reduced motion are supported.

PORTABLE FIXTURE does not prove legal portability compliance, semantic equivalence, vendor compatibility, or a successful real migration. No real account or personal data is accessed.
