# Build 075 — Regulatory Design Comparison System

## Canon

- **075-A:** Regulatory Design Comparison System — compares governance models, institutions, licensing, enforcement, rights, data, financing, and implementation tradeoffs.
- **075-B:** Same Goal, Different Regulatory Machine — shows that jurisdictions pursuing the same synthetic goal can embody fundamentally different regulatory machinery.
- **Creates (exact):** `Regulatory Design Ontology`; `Comparison Workspace`.
- **Lineage (exact):** `[010, 058, 059, 069] -> cap:075`.
- **Registry:** **Same Goal, Different Regulatory Machine** / Compare the actual governance design choices behind similar policy goals.
- **B web:** Regulatory machines reconfigure and propagate tradeoffs when design choices swap.

## Deterministic contract

Engine `075.1.0` admits only three exact frozen presets. Every preset contains exactly five wholly synthetic models pursuing the same illustrative goal and exposes eight ontology dimensions in canonical order: governance, institutions, licensing, enforcement, rights, data, financing, and implementation. Each choice and synthetic evidence identifier is authored fixture data.

The engine compares categorical design choices without scores, weights, aggregation, optimization, recommendations, or ranking. Alpha and Beta presets shift the focal comparison without changing source order. `ALPHA-WITH-BETA-LICENSING` performs one inspectable swap: Alpha's `OPEN-ENTRY` licensing becomes Beta's `LIMITED-PERMITS`. It reports only the immediate synthetic administrative tensions authored in the fixture; it does not predict effects.

Any missing, additional, mutated, hostile, real, authority-bearing, or unrecognized input returns `INVALID`, with no model, row, or tradeoff. There is no free text, network dependency, random behavior, current-law feed, imputation, or inference about any person or place.

## UI and export

075-A uses native select label `DESIGN BASELINE` and button `EXPORT COMPARISON WORKSPACE`. The exact filename is `synthetic-regulatory-design-comparison.json`; its payload contains the engine result, full admission block, exact artifacts, and exact lineage. 075-B begins at Alpha and uses button `SWAP LICENSING MACHINE`; its live status names the change from `OPEN-ENTRY` to `LIMITED-PERMITS` and exposes propagated tradeoffs.

Both routes require semantic headings and controls, visible focus, live status, print support, reduced-motion support, and no horizontal document overflow at 320 CSS pixels.

## Evidence, legal, and interpretation boundaries

All jurisdictions/models, goals, institutions, rules, choices, evidence IDs, and tradeoffs are fictional. No fixture is a proxy for a real jurisdiction. The comparison is not a representation of current law and supplies no legal advice or compliance determination. It does not determine or imply superiority, effectiveness, rights adequacy, enforcement outcomes, equity, safety, access, or any other outcome. It cannot be used for legal, policy, licensing, enforcement, investment, funding, procurement, eligibility, clinical, or resource-allocation decisions.

Differences are categorical and descriptive. The system never scores or ranks models. The licensing swap demonstrates how one design change reconfigures a synthetic administrative machine; it does not establish causal, behavioral, fiscal, legal, or social effects.
