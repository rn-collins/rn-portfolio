## Integrity model — engine 031.2.0

031-A is a deterministic planning aid over a synthetic event fixture. It observes no person or product and collects, transmits, or persists no telemetry. Scores are declared ordinal inputs, not empirical estimates of insight, privacy, identifiability, benefit, necessity, proportionality, or legal risk.

The engine derives a stable minimum event set by covering named decisions in canonical event order. It checks event dependencies and flags events outside the required purposes. `DECLARED MINIMUM SET` means only that the selected IDs exactly match that deterministic coverage set and pass the declared fixture controls; it does not prove real-world necessity or minimization.

Privacy load uses both the maximum selected risk and the average so low-risk events cannot dilute a high-risk event. Identifiability uses the maximum and adds a deterministic linkage term. Row-level link keys, sensitive inference, high-risk combinations, retention beyond the derived 30-day review threshold, and aggregation-with-linkability remain findings. Aggregation is never labeled anonymous.

Consent choice, documented legal-basis review, and tested deletion/expiry procedure are separate assertions. The tool cannot select a legal basis, validate consent, or prove production deletion/retention behavior. Evidence requires unique identity, HTTPS provenance, scope, non-future review, and a 366-day freshness limit.

The explicit local export contains ordered original state, derived assessment, exact replay input, evidence, engine version, privacy boundary, and limitations. Do not enter real identifiers, telemetry, free text, location, health, identity, or confidential data.

031-B communicates the same three states with native Previous/Next controls, live text status, responsive layout, visible focus, and reduced-motion handling. Authenticated browser, physical-device/manual accessibility, production data-flow/deletion verification, contextual legal/security review, GitHub-hosted CI, and LinkedIn media certification remain independent gates.
