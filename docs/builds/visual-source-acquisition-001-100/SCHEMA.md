# Unified visual-acquisition schema

Every Build 001–100 record preserves its canonical visual-source package and adds: `acquisitionDisposition`, `dispositionBasis`, `externalSelected`, `externalStaged`, and `rnFallbackReady`.

## Dispositions

- **CLEARED-NOT-SUBSTITUTED**: an exact official candidate and governing reuse basis passed bounded review. It is not selected, staged, or authorized to replace the RN cover.
- **HOLD**: at least one item-level relevance, creator, rights, permission, credit, geometry, crop, alt, or bounded-claim condition is incomplete. The record must retain an explicit next route.

All external selection/staging fails closed. Every RN cover stays release-eligible. Canva generation is false estate-wide. Recognition never implies affiliation or endorsement.
