# Recognizable entity and visual-source package schema

Each Build 001–034 record includes build ID/title; recognizable entity and relevance; entity-led hook; current cover/opening-frame asset; issuer/creator; rights and permission status; credit; alt text; orientation/dimensions; crop guidance; claim-to-visual scope; official/primary candidate-search log; generated-fallback reason; Canva template/slide types; platform adaptations; CTA; and production status.

## Release gate

An external visual fails closed without exact source page, exact asset URL, issuer/creator, rights statement, permission decision, credit, alt text, dimensions, crop direction and claim-to-visual explanation. Public visibility is not authorization. Creator-owned typography is a fallback, not evidence. Canva generation is outside this audit.
