# Build 020 archive

Decision Evidence Ledger is active at /100-builds/020 with paired routes /a and /b. It inherits human-review architecture (001), explicit entity/relationship structure (010), and acknowledgement/escalation records (019), and creates cap:020.

Public fixtures are synthetic and processed in the browser. No operational or visitor-entered data is collected, submitted or retained. The visitor-initiated JSON export is explicitly labelled synthetic. Build 020.2.0 requires all declared evidence links and represents a correction as a new, linked record while preserving the frozen original fixture.

This demonstration is not an immutable production ledger: it has no authentication, durable storage, cryptographic integrity proof, retention enforcement or domain adjudication. GitHub-hosted CI, authenticated browser review, physical-device/manual accessibility review and LinkedIn media certification remain independent release gates.
