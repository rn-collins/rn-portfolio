# Canonical recognizable-entity and visual-source schema — Builds 001–100

Every sequential record must contain: buildId, title, recognizableEntity (label, type, relevance, authorizationBoundary), entityLedHook, cover (kind, assetUrl, openingFrame, issuerCreator, rightsStatus, licensePermission, credit, altText, orientation, dimensions, cropGuidance, claimToVisualSupport), visualCandidateSearch (status, searched candidates, authorization rule, fallback reason), canva (generationAuthorized, template, slideTypes, notes), platformAdaptations, CTA, and productionStatus.

External clearance fails closed unless the exact asset—not merely its hosting page or issuer—is authorized and credited. Public visibility is never permission, particularly for Indigenous, place, person and community imagery. Canva generation is false unless separately cleared.
