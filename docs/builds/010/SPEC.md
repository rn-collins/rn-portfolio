## Frozen canon

- **Job:** Turn ambiguous concepts into validated entities, fields, relationships, constraints and source rules.
- **A:** An interactive schema workshop with structural validation and local export.

- **Creates:** `cap:010`.

## Contract

An entity has a stable ID, label, definition and typed fields. A field has a stable ID, label, type, required state and source rule. A relationship names its endpoints, meaning and cardinality. A source class names authority, locator and freshness rules.

## Evidence boundary

JSON Schema grounds structural constraints on instance data. W3C SHACL grounds graph validation against reusable shapes. W3C PROV-O informs distinct entities and provenance relationships. Build 010's score and three statuses are product heuristics.

Structural validity does not prove factual truth, semantic correctness, domain completeness, database fitness, interoperability, or governance approval.

## Privacy

The artifact keeps working state in browser memory. Export is explicit and local. No form state is submitted.
