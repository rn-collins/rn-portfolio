# Build 047 — Will This Work Here?

- Job: Test whether a policy, technology, service or program can actually work in a specific place.
- B-Web: Move an intervention between places and watch constraints and adaptations change.
- Uses: 009, 028, 029, 030, 046. Creates: `cap:047`. Direct consumers: 072, 073, 074, 099, 100.

## Product contract

Engine 047.2.0 exact-binds the two invented place profiles and one intervention, uses safe-integer cents, rejects mutated identities and malformed lists, and deterministically recomputes budget, workforce, connectivity, language, mobility and dependency gaps. Export atomically snapshots place, intervention, result and an explicitly state-only replay instruction.

## Boundaries

A score is not feasibility approval, effectiveness evidence, community acceptance, legality, funding, safety, procurement guidance or implementation readiness. Production use requires community-led framing and domain, legal, policy, privacy, security, accessibility and physical-device review.
