# Build 091 — Agent Memory Governance System

Public title: **What Is This AI Allowed to Remember?**

Canonical job: Control what agents may remember, infer, retrieve, share or forget across contexts and time.

B title: **Memory Is a Permissioned Resource**. B mechanism: A memory space changes retrieval permissions and derived-inference paths live.

Artifacts: Memory Policy Engine; Retention & Scope Controls.

Lineage: uses 023, 024, 029, 058, 067; creates cap:091.

## Scope
A deterministic frozen synthetic rehearsal evaluates recall, share, inference and forget requests. It has no live memory, real conversation history, embeddings, browsing, APIs, deletion or external effects. Gate precedence is prohibition/revocation, expiry, purpose, action/share permission, and inference confirmation. Forget produces a minimized local receipt and never claims verified erasure.
