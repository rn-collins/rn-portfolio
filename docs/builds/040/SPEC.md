# Build 040 — AI Stop / Escalate Engine

Frozen canon: test whether an AI knows when to continue, ask, abstain, fall back, escalate or stop. B-Web: a live decision boundary reacts to uncertainty, evidence and consequence changes. Uses 012, 019, 032, 038, 039; creates cap:040.

The paired synthetic experience moves consequence, uncertainty, evidence, tool failure, human availability, fallback, and time pressure through an ordered decision policy; exports locally; and provides keyboard controls, live status, focus, 44px actions, 320px layout, and reduced motion. It does not prove real recognition, safe behavior, or authorization.
