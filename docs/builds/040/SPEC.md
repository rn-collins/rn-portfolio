# Build 040 — AI Stop / Escalate Engine

Frozen canon: test whether an AI knows when to continue, ask, abstain, fall back, escalate or stop. B-Web: a live decision boundary reacts to uncertainty, evidence and consequence changes. Uses 012, 019, 032, 038, 039; creates cap:040.

Engine 040.3.0 evaluates bounded synthetic inputs under a dated policy contract. It validates real calendar dates and evaluates policy and record currency against the declared evaluation date. It requires the exact synthetic ID, version, scope, and evidence binding for one unrevoked record from each inherited control build, a verified fallback before FALLBACK, and a visible priority rule. Urgency never relaxes a high-consequence boundary. STOP is exercised by an explicit no-fallback fixture.

The result is MODELED ACTION SELECTED, not proof that an AI recognizes uncertainty, consequence, evidence sufficiency, authority, fallback safety, legal duties, or real-world harm. Replay recomputes exported state and never repeats external side effects.
