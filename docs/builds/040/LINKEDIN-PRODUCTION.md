## Storyboard and on-screen transcript

The film is silent-first. All meaning is present as on-screen text; these six scenes run for three seconds each.

1. **CONFIDENCE IS NOT PERMISSION TO CONTINUE.** A fluent answer can conceal missing evidence, failed tools, high consequence, or uncertainty that should change the next action.
2. **CONSEQUENCE · EVIDENCE · UNCERTAINTY.** Use a dated versioned policy. Name required controls, accountable humans, tool dependencies, verified fallbacks, and expiry before selecting an action.
3. **CONTINUE · ASK · ABSTAIN.** Continue only inside the declared boundary. Ask when evidence can be repaired. Abstain when the model lacks a safe or authorized path.
4. **FALL BACK · ESCALATE · STOP.** Require a verified fallback after a required tool fails. Escalate high-consequence uncertainty. Stop when neither control is available.
5. **TIME PRESSURE NEVER LOWERS THE GATE.** Preserve the rule, reason, blockers, inherited control records, and exact state-only replay without invoking tools or repeating side effects.
6. **MAKE THE NEXT ACTION EXPLICIT.** A safe boundary makes continue, ask, abstain, fall back, escalate, and stop explicit.
