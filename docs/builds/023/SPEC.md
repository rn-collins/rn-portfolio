# Build 023 specification

## Frozen canon

- Title: Consent & Data Rights Manager
- Job: Let people understand and control consent, access, correction, deletion, retention and downstream use.
- B-Web: A static checkbox becomes a living rights and permission surface.
- Uses: 010 and 020
- Creates: cap:023

## Derived implementation

The question, thesis, fixtures, thresholds, labels, and interface copy are derived implementation choices. The functional build separates permissions by specific purpose, preserves append-only state changes, exposes retention and downstream-use terms, and routes access, correction, deletion, and withdrawal controls. It does not determine whether consent is legally valid or whether a legal right applies.
