# Recognizable entity and visual-source package schema

Each Build 068–100 record must include: build ID/title; recognizable entity and relevance; entity-led hook; current cover/opening-frame asset; issuer/creator; rights and permission status; credit; alt text; orientation/dimensions; crop guidance; claim-to-visual scope; exhaustive official/primary candidate-search log; generated-fallback reason; Canva template/slide types; platform adaptations; CTA; and production status.

## Release gate

A package fails closed when any external visual lacks an exact source page, exact asset URL, issuer/creator, rights statement, permission decision, credit, alt text, dimensions, crop direction, and claim-to-visual explanation. Public visibility never substitutes for authorization. Creator-owned typography must be labeled as a generated fallback, not documentary evidence. Canva generation is outside this audit.
