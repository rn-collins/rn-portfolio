# Build 044 — Reuse the Parts That Regulation Keeps Requiring

Frozen canon: turn recurring approvals, consent, evidence, disclosures and records into reusable regulated components. B-Web: assemble a regulated workflow from components; change context and see invalidation. Uses 010, 014, 017, 020, 023, 029; creates cap:044. Builds 093 and 094 directly consume the capability.

Engine 044.1.0 inspects a bounded synthetic assembly for all five component kinds, unique identity, version, evidence, review and expiry, exact context binding, valid dependency identity and invalidation when jurisdiction, use, consequence or data class changes.

ASSEMBLY VALID means only schema-valid for the declared synthetic context. It does not establish legal compliance, regulatory approval, valid consent, evidence sufficiency, enforceability or safe cross-context reuse.
